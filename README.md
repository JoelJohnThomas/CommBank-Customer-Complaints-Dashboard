# CommBank-Customer-Complaints-Dashboard
An interactive dashboard that helps visualise commbank customer complaints data. The data used is synthetic data.

## 💡 Key insights

- 🧾 **Total complaints:** 467 were lodged between Aug 2011 and Dec 2020.
- ⏱️ **Timely response:** 94.4% were answered on time.
- ⚠️ **Disputed:** 20.6% were disputed, or about 1 in 5.
- 🔄 **In progress:** 34 complaints (7.3%) are still open.
- 📈 **Trend:** Complaints rose 73% from 41 in 2015 to a peak of 71 in 2018, then fell to 49 in 2020.
- 📍 **Top areas:** NSW (31.0%), VIC (25.9%) and QLD (19.9%) make up 76.9% of complaints.
- 🌐 **Top sources:** Web (50.1%) brings in half of all complaints, followed by Referral (29.6%) and Phone (11.6%).
